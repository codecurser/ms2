# Exam Service — Online Examination Portal Microservice

`exam-service` is the second microservice of the microservices-based online examination portal.

It is responsible for allowing authenticated exam creators (`ROLE_CREATOR`) to create and manage examinations, set up exam lifecycle configurations (Draft, Published, Active, Closed, Archived), publish examinations, and generate cryptographically secure public share links for students.

## 🏛️ Microservice Boundary & Ownership

`exam-service` runs on port **`8082`**.

### What this service OWNS:
- `Exam` entities and configurations
- Exam lifecycle state transitions (`DRAFT` → `PUBLISHED` → `ACTIVE` → `CLOSED` → `ARCHIVED`)
- Exam creator ownership (`creatorId` extracted from JWT `sub`)
- Public share codes & student share links

### What this service DOES NOT OWN:
- Creator accounts / user passwords (managed by `auth-service` on port `8081`)
- Questions / Options / Answers (to be owned by `question-service`)
- Student attempts / Evaluation (to be owned by `attempt-service`)

---

## 🔐 Authentication & Ownership Enforcement

All protected creator endpoints require an `Authorization: Bearer <JWT>` header containing a JWT token generated by `auth-service` with `ROLE_CREATOR`.

The `creatorId` is **always extracted directly from the JWT `sub` claim**. Client payloads must never supply a `creatorId`.

Attempts to query or mutate an exam owned by another creator return **`404 Not Found`** to prevent disclosing the existence of internal exam records.

## 📡 REST API Reference

### Protected Creator APIs (`/api/v1/exams`) — Require `ROLE_CREATOR`

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/v1/exams` | Create a new examination draft |
| `GET` | `/api/v1/exams` | Get paginated list of creator's exams (`page`, `size`, `sort`) |
| `GET` | `/api/v1/exams/{examId}` | Get detailed exam by ID |
| `PUT` | `/api/v1/exams/{examId}` | Update exam details |
| `DELETE` | `/api/v1/exams/{examId}` | Delete exam draft (Allowed only if status is `DRAFT`) |
| `POST` | `/api/v1/exams/{examId}/publish` | Publish exam & generate public share code/link |
| `GET` | `/api/v1/exams/{examId}/share-link` | Retrieve share link for published exam |

### Public Student API (`/api/v1/public/exams`) — Unauthenticated

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/public/exams/{shareCode}` | Public student lookup for exam metadata |

## 💻 Running the Service

### Option 1: Docker Compose (Recommended)

Start both PostgreSQL database and `exam-service`:

```bash
docker compose up --build -d
```

Service will be available at: `http://localhost:8082`

Swagger UI will be available at: `http://localhost:8082/swagger-ui.html`

### Option 2: Local Execution via Maven

1. Start PostgreSQL instance on port `5432` with database `exam_db`.
2. Run the application:

```bash
mvn spring-boot:run
```
